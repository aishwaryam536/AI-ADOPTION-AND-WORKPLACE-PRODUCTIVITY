# AI Agent Adoption and Workplace Productivity

## Project Overview

This project analyzes **AI agent adoption and workplace productivity** to understand the relationship between **AI usage, productivity, workload, task automation, employee experience, and AI adoption trends**.

## Objectives

- Analyze AI adoption and usage patterns across employees.
- Understand the relationship between AI usage and productivity.
- Analyze workload and task automation.
- Explore employee experience and AI-related factors.
- Identify key trends and patterns using data analysis and visualization.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook
- MySQL
- SQL
- Power BI
- Excel

## Project Workflow

### 1. Data Cleaning & Preprocessing

Performed data cleaning and preprocessing using **Python, Pandas, and NumPy** to prepare the dataset for analysis.

### 2. Exploratory Data Analysis

Performed **Exploratory Data Analysis (EDA)** using Python and visualizations to identify trends, patterns, and relationships within the dataset.

### 3. SQL Analysis

Used **MySQL and SQL queries** to analyze the dataset and answer business-related questions.

### 4. Power BI Dashboard

Developed an interactive **Power BI dashboard** containing **KPIs, charts, and interactive visualizations** to present key findings and insights.

## Key Analysis Areas

- AI adoption and usage
- Productivity changes
- Task automation
- Employee workload
- Employee experience
- AI skill levels
- Training and AI adoption
- AI-related trends and patterns
